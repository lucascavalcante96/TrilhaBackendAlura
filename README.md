# 🚀 Trilha Backend com Java — Alura

Repositório com anotações, exercícios e projetos desenvolvidos durante a trilha de estudos **Backend com Java** da [Alura](https://www.alura.com.br/).

## 📖 Sobre

Este repositório documenta minha jornada de estudos em desenvolvimento backend utilizando a linguagem Java, cobrindo desde os fundamentos da linguagem até a construção de APIs REST completas com o ecossistema Spring.

## 🎯 Objetivos

- Consolidar os fundamentos de Java e Programação Orientada a Objetos (POO)
- Aprender a construir APIs REST com Spring Boot
- Entender persistência de dados com Spring Data JPA e bancos relacionais
- Praticar boas práticas de testes automatizados
- Aplicar conceitos de segurança, autenticação e autorização
- Conteinerizar aplicações com Docker

## 🛠️ Tecnologias e Ferramentas

- **Java** (JDK 17+)
- **Spring Boot**
- **Spring Data JPA**
- **Spring Security**
- **Maven** / **Gradle**
- **MySQL** / **PostgreSQL**
- **JUnit** / **Mockito**
- **Docker**
- **Git** e **GitHub**
